C. Data Plate — ESFR System
▼
ESFR (Early Suppression Fast Response): Design is based on a fixed number of operating sprinklers at a minimum pressure. Per NFPA 13-2022 §25.8, the demand is the number of design sprinklers × minimum flow, plus hose allowance. No density/area curve is used.

C. Data Plate — CMSA System
▼
CMSA (Control Mode Specific Application): Design uses a specified number of sprinklers at a minimum flow/pressure from the listing. Per NFPA 13-2022 §25.7. Similar to ESFR but at lower pressures with a specific application listing.
